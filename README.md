# Audio Guide

เว็บ audio guide หลายทัวร์ สร้างด้วย Next.js 16 (App Router) + Tailwind CSS 4 + TypeScript ต้องใช้ Node.js 20.9 ขึ้นไป

- สร้างทัวร์ได้ไม่จำกัด: 1 โฟลเดอร์ใน `tours/` = 1 หน้า `/t/<ชื่อโฟลเดอร์>`
- หลายภาษาต่อทัวร์ ทั้งชื่อ เสียง และบทบรรยาย
- session จำกัดเวลา หมดแล้ว redirect ไปหน้าที่ตั้งไว้
- Dashboard ที่ `/admin`: สร้าง/แก้/คัดลอกทัวร์เป็นเทมเพลต อัปโหลดเสียงและรูป ดูคนที่กำลังฟัง
- บัตรเข้าใช้แบบคิวร้านอาหาร: QR ใหม่ทุกใบ เริ่มนับเวลาตอนสแกนครั้งแรก หมดเวลาแล้วใช้ไม่ได้จนกว่าเจ้าหน้าที่ต่อเวลา และตัดสิทธิ์ได้ทันที
- ไฟล์เสียงไม่มี URL สาธารณะ: player ขอลิงก์อายุสั้นที่ผูกกับ session ทีละแทร็ก และจำกัดจำนวนแทร็กต่อนาที
- Player: เล่น/หยุด, ±15 วินาที, ความเร็ว, จำตำแหน่งที่ฟังค้าง, บทบรรยาย, แผนที่ + GPS, ปุ่มบนหน้าจอล็อก, โหมดมืด/สว่าง

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env     # Windows: copy .env.example .env  แล้วแก้รหัสผ่านในไฟล์
npm run dev              # http://localhost:3000  และ Dashboard ที่ /admin
```

| ตัวแปรใน `.env` | ความหมาย |
|---|---|
| `AG_ADMIN_PASSWORD` | รหัสผ่านเข้า `/admin` (ไม่ตั้ง = ปิด Dashboard) |
| `AG_SECRET` | สตริงสุ่มยาว ๆ ใช้เซ็น cookie และลิงก์เสียง ถ้าไม่ตั้งจะสร้างให้เองใน `data/.secret` |
| `AG_MEDIA_LINK_SECONDS` | อายุลิงก์เสียง ค่าเริ่มต้น 90 วินาที |
| `AG_MAX_UPLOAD_MB` | ขนาดไฟล์อัปโหลดสูงสุด ค่าเริ่มต้น 300 MB |
| `AG_TRUST_PROXY=1` | ตั้งเมื่ออยู่หลัง reverse proxy / Cloudflare เพื่ออ่าน IP และ HTTPS ถูกต้อง |
| `AG_TOURS_DIR`, `AG_DATA_DIR` | เปลี่ยนที่เก็บทัวร์ (ค่าเริ่มต้น `tours/`) และข้อมูล session (`data/`) |

คำสั่งอื่น: `npm test` (เทสต์), `npm run lint` (ตรวจ type), `npm run build` แล้ว `npm start` (โหมดใช้งานจริง)

## ใช้งาน Dashboard

1. **ทัวร์ / เทมเพลต** สร้างทัวร์ใหม่ (เลือกภาษา) หรือคัดลอกจากทัวร์เดิม (คัดลอกข้อความ ตั้งค่า และรูป ไม่คัดลอกเสียง)
2. **แก้ไขทัวร์** ชื่อแต่ละภาษา, วิธีเข้า (QR หรือสาธารณะ), เวลา, หน้าที่จะพาไปเมื่อหมดเวลา, สี, รูปปก, จุดต่าง ๆ พร้อมพิกัดและเสียงแต่ละภาษา อัปโหลดเสียงแล้วระบบบันทึกให้ทันที ส่วนอื่นกด "บันทึก" ที่แถบล่าง ทุกครั้งที่บันทึก ไฟล์เดิมจะถูกเก็บเป็น `tour.json.bak`
3. **บัตรเข้าใช้ (QR)** เลือกทัวร์ ตั้งเวลา จำนวนเครื่องต่อรหัส จำนวนบัตร และหมายเหตุ (เช่น โต๊ะ 5) แล้วกด "ออก QR" จะได้แผ่นบัตรพร้อมพิมพ์ ในตารางกด +15/+60 นาที เพื่อต่อเวลาหรือเปิดสิทธิ์คืน และ "ตัดสิทธิ์" เพื่อหยุดทันที
4. **ภาพรวม** ดูว่าใครกำลังฟังอยู่ เหลือเวลาเท่าไร ต่อเวลาหรือตัดสิทธิ์ได้จากหน้านี้

นักท่องเที่ยวสแกน QR → เข้า `/t/<ทัวร์>?code=XXXX` → ระบบตั้ง cookie ให้เครื่องนั้นแล้วเปิด player ถ้าไม่มี QR ก็พิมพ์รหัสบนบัตรในหน้าทัวร์ได้

## โครงสร้างทัวร์

```
tours/wat-pho/
  tour.json
  images/cover.jpg        # เปิดให้โหลดได้ (เฉพาะไฟล์รูป)
  audio/th/01-1.mp3       # ไม่มี URL สาธารณะ เล่นผ่านลิงก์ชั่วคราวเท่านั้น
  audio/en/01-1.mp3
```

ตัวอย่างดูที่ `tours/example-bangkok/tour.json` แก้ไฟล์ตรง ๆ ก็ได้ ระบบโหลดใหม่ภายใน 5 วินาที

## ขึ้นเซิร์ฟเวอร์จริง

แอปเก็บไฟล์ทัวร์และข้อมูล session ลงดิสก์ จึงต้องใช้เครื่องที่มีดิสก์ถาวรและรันโปรเซสเดียว เช่น VPS (DigitalOcean, Vultr, Lightsail) **ไม่เหมาะกับ Vercel หรือ serverless**

```bash
npm ci
npm run build
npm start -- -p 3000      # ใช้ pm2 หรือ systemd ให้รันตลอด
```

วาง Nginx หรือ Caddy ไว้ด้านหน้าเพื่อทำ HTTPS แล้วตั้ง `AG_TRUST_PROXY=1` สำรองโฟลเดอร์ `tours/` และ `data/` เป็นประจำ

## ข้อจำกัดที่ควรรู้

การป้องกันไฟล์เสียงทำให้ดูดยากขึ้น (ลิงก์หมดอายุเร็ว ผูกกับเครื่อง จำกัดความถี่ ปิดคลิกขวา) แต่กันไม่ได้ 100% เพราะคนที่ฟังได้ย่อมอัดเสียงได้ จุดแข็งจริงคือระบบบัตร QR ที่ควบคุมว่าใครเข้าได้ นานเท่าไร
