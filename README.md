# Audio Guide

เว็บ audio guide หลายทัวร์ ใช้ Node.js ล้วน ไม่มี dependency ภายนอก (ต้องใช้ Node 20 ขึ้นไป)

- สร้างทัวร์ได้ไม่จำกัด: 1 โฟลเดอร์ใน `tours/` = 1 หน้า `/t/<ชื่อโฟลเดอร์>`
- หลายภาษาต่อทัวร์ ทั้งชื่อจุด, เสียง, บทบรรยาย และข้อความหน้าเว็บ
- session จำกัดเวลา หมดแล้ว redirect ไปหน้าที่ตั้งไว้ และบันทึกการเข้าทุกครั้ง
- หน้า Dashboard (`/admin`): สร้าง/แก้/คัดลอกทัวร์เป็นเทมเพลต, อัปโหลดเสียงและรูป, ดูคนที่กำลังใช้งาน
- บัตรเข้าใช้แบบคิวร้านอาหาร: ออก QR ใหม่ทุกใบ, เริ่มนับเวลาตอนสแกนครั้งแรก, หมดเวลาแล้วใช้ไม่ได้จนกว่าจะต่อเวลา, ยกเลิกได้ทันที
- ไฟล์เสียงไม่มี URL สาธารณะ: player ขอลิงก์อายุสั้นที่ผูกกับ session ทีละแทร็ก
- player: เล่น/หยุด, ±15 วินาที, ปรับความเร็ว, จำตำแหน่งที่ฟังค้างไว้, บทบรรยาย, แผนที่ + ตำแหน่ง GPS, ปุ่มบนหน้าจอล็อก, ธีมมืด/สว่าง

## เริ่มใช้งาน

```bash
npm start                      # http://localhost:3000
npm test
```

คัดลอก `.env.example` เป็น `.env` แล้วตั้งค่า (หรือตั้งเป็น environment variables):

| ตัวแปร | ความหมาย |
|---|---|
| `AG_ADMIN_PASSWORD` | รหัสผ่านเข้าหน้า Dashboard ที่ `/admin` (ไม่ตั้ง = ปิด Dashboard) |
| `AG_SECRET` | สตริงสุ่มยาว ๆ ใช้เซ็น cookie และลิงก์เสียง ต้องคงเดิมทุกครั้งที่ restart (บังคับเมื่อ `NODE_ENV=production`) |
| `PORT` | พอร์ต ค่าเริ่มต้น 3000 |
| `AG_MEDIA_LINK_SECONDS` | อายุลิงก์เสียง ค่าเริ่มต้น 90 วินาที |
| `AG_MAX_UPLOAD_MB` | ขนาดไฟล์อัปโหลดสูงสุด ค่าเริ่มต้น 300 MB |
| `AG_TRUST_PROXY=1` | ตั้งเมื่ออยู่หลัง reverse proxy / Cloudflare เพื่ออ่าน IP และ HTTPS ถูกต้อง |
| `AG_TOURS_DIR`, `AG_DATA_DIR` | เปลี่ยนที่เก็บทัวร์และข้อมูล session |

## Dashboard

เปิด `http://localhost:3000/admin` แล้วใส่รหัสผ่านจาก `AG_ADMIN_PASSWORD`

- **ภาพรวม:** จำนวนคนที่กำลังฟังแต่ละทัวร์, รายชื่อ session ที่ใช้งานอยู่และเวลาที่เหลือ, ปุ่มต่อเวลา +30 นาที และตัดสิทธิ์
- **ทัวร์ / เทมเพลต:** สร้างทัวร์ใหม่ หรือคัดลอกจากทัวร์ที่มีอยู่ (ได้ข้อความ จุด และรูป แต่ไม่รวมไฟล์เสียง) แก้ชื่อ จุด พิกัด บทบรรยาย และอัปโหลดเสียงแยกภาษาได้จากหน้าเว็บ ทุกครั้งที่บันทึกจะเก็บไฟล์เดิมไว้เป็น `tour.json.bak`
- **บัตรเข้าใช้ (QR):** เลือกทัวร์ เวลา จำนวนเครื่องต่อ QR จำนวนใบ และหมายเหตุ (เช่น โต๊ะ 5) แล้วกดออก QR จะได้การ์ด QR พร้อมพิมพ์

### บัตรเข้าใช้ทำงานอย่างไร

เหมือนบัตรคิวในร้านอาหาร:

1. ทัวร์ต้องตั้งโหมดเป็น "ต้องสแกน QR" (`access.mode: "code"`)
2. QR แต่ละใบเป็นรหัสใหม่เสมอ ลิงก์คือ `/t/<ทัวร์>?code=<รหัส>`
3. เวลาเริ่มนับตอนสแกนครั้งแรก ใช้ได้ไม่เกินจำนวนเครื่องที่ตั้งไว้
4. หมดเวลาแล้ว ลูกค้าจะถูกพาไปหน้าที่ตั้งใน `expiredRedirect` และสแกนซ้ำไม่ได้
5. เจ้าหน้าที่กดต่อเวลาได้ แม้หมดเวลาหรือถูกยกเลิกไปแล้ว (เปิดสิทธิ์ใหม่) โทรศัพท์ของลูกค้าจะเห็นเวลาใหม่ภายใน 20 วินาที
6. กดยกเลิกแล้ว หน้าของลูกค้าจะเด้งออกภายใน 20 วินาที

ทุกเหตุการณ์ถูกบันทึกใน `data/events.jsonl` และสถานะ QR อยู่ใน `data/passes.json`

QR ใช้ที่อยู่เว็บที่คุณเปิด Dashboard อยู่ ถ้าจะพิมพ์ QR ให้ลูกค้าใช้จริง ให้เปิด Dashboard ผ่านโดเมนจริง ไม่ใช่ `localhost`

## เพิ่มทัวร์ใหม่

```bash
npm run new-tour -- wat-pho th en zh
```

หรือสร้างจาก Dashboard ก็ได้ จะได้โฟลเดอร์ `tours/wat-pho/` ที่มี `tour.json` กับ `audio/<ภาษา>/` แล้ว:

1. ใส่ไฟล์เสียงของคุณใน `audio/th/01.mp3`, `audio/en/01.mp3` ...
2. ใส่รูปใน `images/` แล้วใส่ชื่อไฟล์ใน `heroImages` เช่น `"images/cover.jpg"`
3. แก้ `tour.json` (ดูตัวอย่างใน `tours/example-bangkok/tour.json`)

ฟิลด์ใน `tour.json`:

- `title`, `subtitle`: ข้อความแยกตามภาษา `{ "th": "...", "en": "..." }`
- `languages`: ภาษาที่มี `{ "th": { "label": "ไทย" } }`
- `access.mode`: `"open"` (เปิดลิงก์แล้วเริ่มนับเวลา) หรือ `"code"` (ต้องใช้รหัส)
- `access.sessionMinutes`: เวลาใช้งานต่อ session (นาที)
- `access.expiredRedirect`: หน้าที่จะพาไปเมื่อหมดเวลา เช่น หน้าขายทัวร์ของคุณ
- `access.maxTracksPerMinute`: จำนวนแทร็กไม่ซ้ำที่ขอได้ต่อนาที
- `stops[]`: จุดในทัวร์ แต่ละจุดมี `title`, `transcript`, `lat`/`lng` (ไม่ใส่ก็ได้), `audio` แยกตามภาษา
- `links[]`: ปุ่มลิงก์ใต้ player `{ "label": { "th": "จองทัวร์" }, "url": "https://..." }`
- `theme.accent`: สีหลัก เช่น `"#0f766e"`
- `listed: false`: ไม่แสดงในหน้ารายการทัวร์

ไฟล์ `tour.json` ถูกอ่านใหม่ทุก 5 วินาที แก้แล้วไม่ต้อง restart

## การป้องกันไฟล์เสียง และข้อจำกัด

ที่ทำแล้ว:

- ไฟล์เสียงไม่ได้อยู่ใน path สาธารณะ เปิด `/t/<tour>/audio/...` ตรง ๆ ไม่ได้
- ลิงก์เสียงหมดอายุใน 90 วินาที และใช้ได้กับ cookie ของ session นั้นเท่านั้น ก๊อปลิงก์ไปเปิดที่อื่นจะได้ 403
- session หมดเวลาแล้วลิงก์ทั้งหมดใช้ไม่ได้
- จำกัดจำนวนแทร็กต่อนาที กันการโหลดทั้งทัวร์รวดเดียว
- player ไม่ใช้ตัวควบคุมของเบราว์เซอร์ และปิดเมนูคลิกขวา จึงไม่มีเมนู "Save audio as"

ที่กันไม่ได้: คนที่ตั้งใจจริงยังอัดเสียงขณะเล่น หรือดึงข้อมูลผ่าน DevTools ได้ ไม่มีเว็บไหนกันได้ 100% แนะนำให้:

- แทรกเสียงชื่อแบรนด์สั้น ๆ ในไฟล์เสียง (audio watermark)
- เขียนประกาศลิขสิทธิ์ไว้ในหน้าเว็บ
- ถ้าเจอคนเอาไปใช้ แจ้งลบกับแพลตฟอร์มที่เขาโพสต์ (DMCA / แจ้งละเมิดลิขสิทธิ์)

ไฟล์เสียงใน `tours/*/audio/` ถูก `.gitignore` ไว้ ไม่ขึ้น git ให้อัปโหลดไปที่ server โดยตรง

## Deploy

เป็น Node process เดียว เก็บข้อมูลเป็นไฟล์ใน `data/` จึงต้องใช้ host ที่มีดิสก์ถาวร เช่น VPS, Railway หรือ Render (แบบมี disk) แล้วตั้ง `AG_SECRET`, `AG_ADMIN_PASSWORD`, `NODE_ENV=production` และใส่ HTTPS ด้านหน้า
